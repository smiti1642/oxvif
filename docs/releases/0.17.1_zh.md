# oxvif 0.17.1

發布日期：2026-10-23。

本版以 v0.17.0 為基礎，只更新安全依賴；master 上後續新增功能與 mock
行為變更不在本版範圍。oxvif 與 oxvif-cli 同步發布 0.17.1。

- rustls 0.23.46、rustls-webpki 0.103.16、webpki-root-certs 1.0.10
  修補 TLS 問題並拒絕已遭入侵的 emSign 中繼金鑰，同步更新必要的 aws-lc 依賴。
- quinn-proto 0.11.18 修補連線狀態與 datagram 記憶體耗盡問題。
- 保持 0.17.0 公開 API、CLI schema、憑證儲存後端及執行行為。

CLI 請使用 `cargo install oxvif-cli --version 0.17.1 --locked`。
函式庫使用者仍需更新自己應用程式的 Cargo.lock，並保持作業系統信任與撤銷資料最新。
未啟用的非同步 Linux 憑證依賴仍有上游維護警告，未新增 audit 忽略規則。

詳見[英文發布說明](0.17.1.md)。
