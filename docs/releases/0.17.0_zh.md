## 重點

- **連續的 CLI 工作區。** `oxvif manage` 保留探索結果、篩選、所選 Profile 及各攝影機
  狀態。可在同畫面新增攝影機、切換裝置並返回先前結果，不必重複整個流程。
- **實用的維運命令。** 診斷攝影機、下載有大小限制且禁止覆寫的快照、匯出唯讀設定
  並比較清冊。操作失敗或取消後仍保留先前證據。
- **更清楚的終端操作。** 數字前綴 Vim 移動、`gg`／`G`、Ctrl+D/U、可設定行號、
  固定底部狀態列及填滿視窗高度的清單。`?` 分別提供行號及按鍵說明頁。
  JSON／JSONL 自動化使用相同操作，不會出現選單。
- **更可靠的快照認證。** CLI／health 共用下載器，處理韌體標頭大小寫差異，
  並保留 Digest、TLS 及重新導向安全限制。
- **基本多攝影機 Mock。** `mock_fleet_serve` 範例以單一程序執行可獨立設定的
  虛擬裝置，並提供明確啟用的 LAN 探索。
- **更嚴謹的選定 Mock 與 replay 契約。** Media 寫入先驗證完整候選設定再提交；
  未建模效果必須明確選用僅回條模式。錄製鍵值碰撞時，儲存、載入與重播仍保留不同請求。
- **新增函式庫 API。** 讀取通知的 TCP peer 資訊，以及要求 Media1／Media2 Profile
  同步。[完整變更紀錄](0.17.0-changelog_zh.md)保留原始貢獻者署名。

## 升級前須知

此 minor 版本包含原始碼不相容變更：Media2 幀率改用 `f32`，metadata 結構要求
完整 multicast／session-timeout 欄位；舊有不完整 Mock fixture 可能改為回傳 Fault。
請先閱讀[完整變更與遷移指南](0.17.0-changelog_zh.md#不相容變更與遷移)。

設定匯出不是可還原備份；診斷不驗證 RTSP 播放。Mock Fleet 不提供影片串流、
品牌模擬或 64／256 台長時間穩定性保證。Mock 回條及 XML 驗證不代表實體效果或
ONVIF 認證。降版前請備份錄製資料：舊版 reader 可能再次合併碰撞項目。
