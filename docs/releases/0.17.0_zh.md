## 主要改變

- **引導式攝影機維護介面。** `oxvif manage` 保留所選攝影機及 profile，
  用於診斷、快照與設定檢視。
  網路搜尋結果支援 `/` 搜尋及已存／未存／全部篩選；操作返回或取消輸入憑證後，
  保留選單位置。
- **更完整的診斷與檔案流程。** 在大小限制內儲存快照且不覆寫既有檔案；
  匯出唯讀設定並比較清冊。後續診斷階段失敗時，仍保留先前檢查結果。
- **更可靠的快照認證。** CLI 與 health 檢查共用有界限的下載器，處理韌體的
  HTTP 欄位大小寫相容問題，同時保留 Digest、TLS 與重新導向安全限制；
  非影像回應仍判定失敗。
- **一致的終端導覽。** 支援帶次數的 Vim 移動、`gg`／`G`、半頁移動、
  可調整行號及獨立固定底部狀態列，將模式、位置及 BUSY 經過時間與操作提示分開。
  輸入欄位保留一般文字編輯，機器輸出不開啟選單。
- **新增 Library API。** 在不改動 ONVIF 通知內容的情況下取得 TCP peer，
  並支援 Media1／Media2 profile 同步請求。
- **更嚴格的 Mock 契約。** 選定 Media 操作先驗證完整候選再提交；
  已分類但未建模的效果預設拒絕，僅收件確認須明確選用。
- **保留碰撞的錄製資料。** 相同 legacy key 下的不同請求在保存、載入及 replay
  中維持獨立；僅提供具有歧義的 key 時不再任意選取錄製。

## 升級前注意事項

此候選次版本包含原始碼不相容變更。Metadata 結構改用完整 multicast／
session timeout 資料；Media2 及 Mock frame rate 改為 `f32`。
既有不完整或具有歧義的 Mock fixture 可能改為回傳 fault。升級前請閱讀
[完整變更及遷移指南](0.17.0-changelog_zh.md#不相容變更與遷移)。

設定匯出**不是可還原備份**；診斷不驗證 RTSP 播放。Mock 收件確認與合法 XML
不能證明實際硬體效果或 ONVIF 認證。先前候選／安全審查及
[`fed6777` 的原生 CI](https://github.com/smiti1642/oxvif/actions/runs/34672460802) 僅對
記錄的輸入通過，不涵蓋後續 CLI／Fleet 變更。合併開發內容的 Windows 批次為
1,316 通過、0 失敗、6 項跳過，詳見[目前證據及排除項目](../active/mock-fleet-basic-plan_zh.md#跳過測試明細)。
目前候選 CI、散布 staging、最終版號套件及其餘人工／平台驗收仍未完成，實機證據保留範圍限制。
降版前應備份錄製，舊讀取器可能再次合併碰撞群組。

## 尚未確認收錄的開發功能

[可設定的 Mock Fleet 啟動器](../mock-fleet_zh.md) 已完成實作及本機測試，提供
單一程序、獨立設備、啟動設定與明確啟用的基本共用探索。是否納入 0.17 仍待決定。
不提供 RTSP 串流或 scope 篩選比對；原生 LAN／VMS 驗收仍未完成。

本預覽使用儲存庫相對連結及固定提交連結，不依賴暫時分支網址。正式發布前仍須
將套件連結固定至版本 tag，並填入已驗證的安裝方式。0.17.0 尚不能透過
`cargo install`、APT、Homebrew、winget 或 Chocolatey 安裝。
