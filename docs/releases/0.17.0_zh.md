## 主要改變

- **引導式攝影機維護介面。** `oxvif manage` 保留所選攝影機及 profile，
  用於診斷、快照與設定檢視。
- **更完整的診斷與檔案流程。** 在大小限制內儲存快照且不覆寫既有檔案；
  匯出唯讀設定並比較清冊。後續診斷階段失敗時，仍保留先前檢查結果。
- **一致的終端導覽。** 支援帶次數的 Vim 移動、`gg`／`G`、半頁移動、
  精簡狀態列及可調整行號。輸入欄位保留一般文字編輯，機器輸出不開啟選單。
- **新增 Library API。** 在不改動 ONVIF 通知內容的情況下取得 TCP peer，
  並支援 Media1／Media2 profile 同步請求。
- **更嚴格的 Mock 契約。** 選定 Media 操作先驗證完整候選再提交；
  已分類但未建模的效果預設拒絕，僅收件確認須明確選用。

## 升級前注意事項

此候選次版本包含原始碼不相容變更。Metadata 結構改用完整 multicast／
session timeout 資料；Media2 及 Mock frame rate 改為 `f32`。
既有不完整或具有歧義的 Mock fixture 可能改為回傳 fault。升級前請閱讀
[完整變更及遷移指南](https://github.com/smiti1642/oxvif/blob/codex/contributor-pr-integration/docs/releases/0.17.0-changelog_zh.md#不相容變更與遷移)。

設定匯出**不是可還原備份**；診斷不驗證 RTSP 播放。Mock 收件確認與合法 XML
不能證明實際硬體效果或 ONVIF 認證。包含 replay 儲存阻擋問題及原生平台關卡在內，
發布驗收仍未完成。
