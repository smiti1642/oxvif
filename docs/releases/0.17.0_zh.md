## 重點

- **集中處理攝影機維護。** `oxvif manage` 保留探索結果、篩選及各攝影機狀態，
  可在同畫面新增及切換裝置，不必重新開始。
- **診斷、存檔與比較。** 診斷攝影機、保存禁止覆寫的快照、匯出唯讀設定並比較差異。
- **更順手的終端操作。** 適應視窗的清單、底部狀態列、Vim 式導覽、可設定行號，
  以及 `?` 情境按鍵說明。
- **更可靠的快照下載。** 改善部分攝影機韌體的認證相容性，同時保留安全防護。

Agent 可透過 JSON／JSONL 使用相同維護操作，不會出現互動選單。
詳見 [CLI 指南](https://github.com/smiti1642/oxvif/blob/v0.17.0/docs/oxvif-cli_zh.md)。
