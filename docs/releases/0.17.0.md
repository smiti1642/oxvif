## Highlights

- **A continuous CLI workspace.** `oxvif manage` retains discovery results,
  filters, selected profiles and per-camera state. Add cameras inline, switch
  devices and return to prior results without repeating the workflow.
- **Practical maintenance commands.** Diagnose cameras, save bounded snapshots
  without overwriting files, export read-only settings and compare inventories.
  Failed or cancelled operations retain earlier evidence.
- **Clearer terminal navigation.** Counted Vim movement, `gg` / `G`,
  Ctrl+D/U, configurable line numbers, a fixed-bottom status bar and lists that
  fill the terminal height. `?` exposes separate line-number and key-binding tabs.
  JSON/JSONL automation uses the same operations without menus.
- **More reliable snapshot authentication.** Shared CLI/health downloads handle
  firmware header-casing quirks while retaining Digest, TLS and redirect safeguards.
- **Basic multi-camera Mock serving.** A configurable `mock_fleet_serve` example
  runs independent virtual devices in one process with opt-in LAN discovery.
- **Stricter selected Mock and replay contracts.** Media writes validate complete
  candidates before commit; unmodeled effects require receipt-only opt-in.
  Colliding recording keys retain distinct requests through save/load and replay.
- **Additional library APIs.** Read notification TCP-peer metadata and request
  Media1/Media2 profile synchronization. Original contributor attribution is
  retained in the [full changelog](0.17.0-changelog.md).

## Before upgrading

This minor release contains source-breaking changes: Media2 frame rates use
`f32`, and metadata structs require structured multicast/session-timeout values.
Older partial Mock fixtures may now fault. Read the
[full changelog and migration guide](0.17.0-changelog.md#breaking-changes-and-migration).

Configuration exports are not restorable backups; diagnosis does not verify RTSP
playback. Mock Fleet does not provide video streams, brand emulation or a sustained
64/256-device stability guarantee. Mock receipts and XML validation do not prove
physical effects or ONVIF certification. Back up recordings before downgrading:
older readers can collapse collision buckets.
