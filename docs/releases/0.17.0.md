## Highlights

- **A guided camera-maintenance workspace.** `oxvif manage` retains the selected
  camera and profile for diagnosis, snapshots and configuration inspection.
  Network results support `/` search and saved/new/all filters; returning from
  operations or credential cancellation preserves menu position.
- **More useful diagnostic and file workflows.** Save a bounded snapshot without
  overwriting an existing file; export read-only settings and compare inventories.
  Diagnosis retains earlier checks when a later stage fails.
- **More reliable snapshot authentication.** CLI and health checks share a bounded
  downloader that handles firmware header-casing quirks without weakening Digest,
  TLS or redirect safeguards. Non-image responses remain failures.
- **Consistent terminal navigation.** Counted Vim movement, `gg` / `G`,
  half-page navigation and configurable line numbers. A distinct fixed-bottom
  status bar separates mode, position and elapsed BUSY time from key hints.
  Input fields retain normal typing; machine output never opens menus.
- **Additional library APIs.** Observe the TCP peer of push notifications without
  changing the ONVIF payload, and request Media1/Media2 profile synchronization.
- **Stricter Mock contracts.** Selected Media operations validate complete
  candidates before committing; classified unmodeled effects refuse by default
  and require explicit receipt-only opt-in.
- **Collision-safe recording retention.** Distinct requests sharing a legacy
  key remain separate through save/load and replay; ambiguous key-only lookups
  no longer select an arbitrary recording.

## Before upgrading

This is a source-breaking minor release candidate. Metadata structs now require
structured multicast/session-timeout data; Media2 and mock frame rates use
`f32`. Older partial or ambiguous mock fixtures may now fault. Read the
[complete changes and migration guide](0.17.0-changelog.md#breaking-changes-and-migration)
before updating.

Configuration exports are **not restorable backups**; diagnosis does not verify
RTSP playback. Mock receipts and valid XML do not prove physical effects or ONVIF
certification. Earlier candidate/security review and
[native CI at `fed6777`](https://github.com/smiti1642/oxvif/actions/runs/34672460802) passed
for their recorded inputs, not the later CLI/Fleet changes. The combined Windows
development batch passed 1,316 tests with zero failures and six ignored checks;
see the [current evidence and exclusions](../active/mock-fleet-basic-plan.md#ignored-tests).
Current-candidate CI, distribution staging, final-version package checks and remaining human/platform
acceptance are still open; hardware evidence remains scoped. Back up recordings
before downgrading to an older reader, which can collapse collision buckets again.

## Development outside the confirmed cut

A [configurable Mock Fleet runner](../mock-fleet.md) is implemented and locally
tested: one process, independent devices, startup configuration and opt-in basic
shared discovery. Its inclusion in 0.17 remains undecided. It provides no RTSP
streams or scope-filter matching; native LAN/VMS acceptance remains open.

This preview uses repository-relative links and immutable commit links instead
of temporary branch URLs. Publication still requires version-tagged package links
and verified installation instructions. Version 0.17.0 is not yet available through
`cargo install`, APT, Homebrew, winget or Chocolatey.
