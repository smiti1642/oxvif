# oxvif 0.17.0 / oxvif-cli 0.17.0

Release date: 2026-09-14.

Headline: **discover, diagnose and maintain cameras without restarting your CLI
workflow.** Version 0.17 adds a continuous maintenance workspace, snapshot saving
and settings comparison, with more consistent terminal navigation and improved
snapshot compatibility. Agents access the same maintenance operations through
structured commands.

### Added

- **`oxvif manage`: one workspace for camera maintenance.** Choose a saved camera
  or discover one on the network, select its media profile, then diagnose, save
  snapshots or inspect settings without retyping the device ID. Switching cameras
  and returning to an operation preserves each camera's profile, results and menu
  state for the current session.

- **`oxvif diagnose`: staged reports with actionable evidence.** Inspect device,
  profile, URI and snapshot checks in a summary-first report; use `-v` for details.
  When a later check fails, completed stages remain available. Multiple profiles
  require a choice rather than silently selecting a stream.

- **Save snapshots directly to a file.** `oxvif snapshot CAMERA --save image.jpg`
  downloads a recognized image instead of only returning its URI. Downloads are
  size-limited, and existing destination files are never overwritten.

- **Export and compare camera settings.** `oxvif config export CAMERA --save settings.json`
  creates a read-only inventory; `oxvif config diff CAMERA --against settings.json`
  compares it with the camera's current settings. Reports distinguish actual
  differences from sections that could not be compared.

### Fixed

- **Returning to discovery no longer means rescanning.** Within `manage`, results,
  text and saved/new filters, selection and scroll position survive navigation.
  `R` explicitly rescans; a failed or cancelled scan keeps the previous results.

- **Adding cameras stays in the same interface.** Inline setup supports retries
  and consecutive additions. Selecting a newly discovered camera does not save it
  automatically; `a` explicitly verifies and saves it.

- **Snapshot authentication works with more affected firmware.** CLI and health
  checks share a downloader that handles demonstrated HTTP header-casing quirks
  while retaining Digest authentication, TLS verification and redirect safeguards.
  Non-image responses are still reported as failures.

### Changed

- **Consistent, configurable terminal navigation.** Lists fill the available
  window height. Use counted `j/k`, `gg/G`, PgUp/PgDn or Ctrl+D/U, with a separate
  bottom status bar. `?` opens distinct line-number and contextual key-binding
  pages; choose absolute, relative, hybrid or no line numbers.

- **Human and Agent workflows share the same maintenance evidence.** JSON/JSONL
  commands expose profile-selection reasons, partial reports and untested checks
  without opening menus. Agent guide v8 documents these workflows; envelope
  schema v3 remains unchanged.

### Breaking and limitations

- Library users must account for Media2 frame rates changing to `f32` and
  structured metadata multicast/session-timeout fields. See the migration guide
  before upgrading existing applications or test fixtures.
- Settings exports are **not restorable backups**. Diagnosis does **not verify
  RTSP playback or video decoding**.

### Verification

The 0.17 candidate passed Windows, Linux and macOS CI and non-publishing
APT/Homebrew installation staging. These checks do not mean admission to official
package repositories; exact evidence and remaining limits are in the full record.
