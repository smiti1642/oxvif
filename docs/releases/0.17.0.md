# oxvif 0.17.0 / oxvif-cli 0.17.0

[English](0.17.0.md) | [繁體中文](0.17.0_zh.md)

Status: Unreleased
Release date: not scheduled. This is the proposed release summary, not an available package.

## Highlights

- **A guided camera-maintenance workspace.** `oxvif manage` retains the selected
  camera and profile for diagnosis, snapshots and configuration inspection.
- **More useful diagnostic and file workflows.** Save a bounded snapshot without
  overwriting an existing file; export read-only settings and compare inventories.
  Diagnosis retains earlier checks when a later stage fails.
- **More reliable snapshot authentication.** CLI and health checks share a bounded
  downloader that handles firmware header-casing quirks without weakening Digest,
  TLS or redirect safeguards. Non-image responses remain failures.
- **Consistent terminal navigation.** Counted Vim movement, `gg` / `G`,
  half-page navigation, compact status lines and configurable line numbers.
  Input fields retain normal typing; machine output never opens menus.
- **Additional library APIs.** Observe the TCP peer of push notifications without
  changing the ONVIF payload, and request Media1/Media2 profile synchronization.
- **Stricter Mock contracts.** Selected Media operations validate complete
  candidates before committing; classified unmodeled effects refuse by default
  and require explicit receipt-only opt-in.
- **Collision-safe recording retention.** Distinct requests sharing a legacy
  key remain separate through save/load and replay; ambiguous key-only lookups
  no longer select an arbitrary recording.

## Before upgrading

This is a source-breaking minor release candidate. Metadata structs now require
structured multicast/session-timeout data; Media2 and mock frame rates use
`f32`. Older partial or ambiguous mock fixtures may now fault. Read the
[complete changes and migration guide](https://github.com/smiti1642/oxvif/blob/codex/release-0.17-closure/docs/releases/0.17.0-changelog.md#breaking-changes-and-migration)
before updating.

Configuration exports are **not restorable backups**; diagnosis does not verify
RTSP playback. Mock receipts and valid XML do not prove physical effects or ONVIF
certification. Local candidate/security review passed; final-candidate native CI,
staging, package and remaining human/platform acceptance remain open. Hardware
evidence remains scoped. Back up recordings before downgrading to an
older reader, which can collapse collision buckets again.
