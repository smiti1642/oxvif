## Highlights

- **Maintain cameras in one workspace.** `oxvif manage` keeps discovery results,
  filters and per-camera state. Add cameras inline and switch devices without starting over.
- **Diagnose, save and compare.** Diagnose cameras, save snapshots without
  overwriting files, export read-only settings and compare changes.
- **Navigate more comfortably.** Responsive lists, a bottom status bar, Vim-style
  movement, configurable line numbers and contextual `?` key-binding help.
- **More reliable snapshot downloads.** Improved authentication compatibility
  with affected camera firmware while preserving security safeguards.

Agents can use the same maintenance operations through JSON/JSONL without menus.
See the [CLI guide](https://github.com/smiti1642/oxvif/blob/v0.17.0/docs/oxvif-cli.md).

## Before upgrading

Library users: this release includes source-breaking changes.
Read the [full changelog and migration guide](https://github.com/smiti1642/oxvif/blob/v0.17.0/docs/releases/0.17.0-changelog.md)
for API, testing and Mock/replay details. Settings exports are not restorable
backups; diagnosis does not verify video playback.
