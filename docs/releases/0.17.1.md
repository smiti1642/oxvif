# oxvif 0.17.1

Released: 2026-10-23.

This security-only patch releases oxvif and oxvif-cli together, based on
v0.17.0. It does not include the later feature and mock-behavior work on master.

- Update rustls to 0.23.46, rustls-webpki to 0.103.16 and
  webpki-root-certs to 1.0.10 for TLS security fixes and rejection of compromised
  emSign intermediate keys (RUSTSEC-2026-0285, RUSTSEC-2026-0382 and
  RUSTSEC-2026-0383). Update the required aws-lc dependency graph.
- Update quinn-proto to 0.11.18 for the connection-state and datagram memory
  exhaustion advisories RUSTSEC-2026-0338 through RUSTSEC-2026-0342.
- Keep the public APIs, CLI schema, credential backends and application behavior
  of 0.17.0. Any build-lint adjustments preserve runtime behavior.

Install the rebuilt CLI with:

```sh
cargo install oxvif-cli --version 0.17.1 --locked
```

Library consumers must update their own Cargo.lock files to the patched versions
above or later. Publishing a library does not replace an application's locked
transitive dependencies. Keep operating-system trust and revocation data current
for native certificate verification.

The remaining zvariant/zbus_names maintenance warnings belong to the optional
asynchronous Linux credential graph; the selected CLI backend uses synchronous
Secret Service. No advisory ignores are added. This release does not claim to
resolve those upstream maintenance warnings.

Direct dependency updates were reviewed with cargo outdated. Non-security
feature/major upgrades are left for the next feature release; the patch retains
the 0.17.0 manifest dependency requirements except the CLI's matching oxvif version.
