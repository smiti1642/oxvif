## 實作

1. [x] 新增限互動終端的 `manage`：選擇已存／搜尋到的設備，保留設備與 profile，
   串接診斷、profile 檢視、快照保存、設定匯出／比較及結果詳情，不反覆輸入 ID。
2. [x] 共用應用層操作，session 最長快取 60 秒；標示重用或重新連線，失敗後失效。
   快取不代表仍在線，不自動重試檔案寫入。
3. [x] 顯示設備提供的編碼／解析度／FPS，缺值明確標示；補充查詢有界，`i` 顯示
   詳情。不推測主副串流，不將設定 FPS 當作實測 FPS。
4. [x] 共用診斷判讀：主要已觀察問題、受阻檢查、未實作限制及處置建議。保留
   schema v3 欄位與退出碼，Agent 取得相同事實。
5. [x] 同步中英文文件、README 摘要、指令描述、Agent guide 與 Unreleased
   changelog。JSON／非互動呼叫不得進入 manage。

## 驗收

- 主 Agent 先做單元／mock／執行檔測試及終端操作，涵蓋取消、輸入、尺寸、失敗
  復原、session 重用／到期、防覆寫及結構化輸出對齊。
- Workspace 預設／全功能測試與 clippy、格式及最低 Rust 版本檢查。
- 實作及自行測試完成後，開一個獨立 SubAgent，以初次使用者思路操作並批評。
  優先依執行檔／終端體驗判斷，不先閱讀實作；僅使用隔離的本機 mock，不連實機。
- 修正可採取行動的意見，重跑相關測試，記錄剩餘限制。
- 實機及其他平台原生發布驗收另行執行。

## 結果

Windows x64，2026-09-09：

- Workspace 全功能：**1,105 項通過、4 項既有條件式忽略**。
- Workspace 預設：**1,025 項通過、4 項既有條件式忽略**。
- 兩種 workspace／all-targets clippy（`-D warnings`）、格式、Rust 1.88
  workspace／all-targets／all-features 及 CLI rustdoc 警告視為錯誤檢查均通過。
- 回歸涵蓋中繼資料失敗仍保留 profiles、session 重用／到期／失敗失效、防覆寫、
  匯出／比較、觀察式判讀、JSON 拒絕、Unicode／游標捲動與密碼遮蔽。
- 主 Agent 透過 Windows ConPTY 選擇已存設備及 Profile_2，完成診斷與合成快照保存，
  取消下一次路徑輸入後正常退出。另以本機延遲端點確認 Escape 可取消網路等待，
  返回工作區並標示需重新連線。
- 初次執行檔回歸發現新增 async 狀態導致 Windows debug stack overflow；將 manage
  分支配置於 heap 後修正，完整執行檔回歸通過。
- 主 Agent 測試後提供固定執行檔給一位獨立 SubAgent；它先使用 help 與終端，不先
  閱讀實作或指南，獨立完成診斷、快照、匯出、比較及取消。

| Critic 發現 | 修正與針對性複驗 |
| --- | --- |
| P2：長路徑隱藏檔名／游標 | 加入水平捲動及 UTF-8 安全的 Left／Right／Home／End 編輯，於 80 欄終端複驗。 |
| P2：錯誤目的路徑被清空 | 保留輸入；Critic 僅刪除中間的錯誤目錄便成功保存，無須重打路徑。 |
| P3：既有檔案錯誤使用 registry ID 術語 | 改為檔案專用訊息及目的路徑建議，複驗仍拒絕覆寫。 |
| P3：詳情頁重複要求 `-v` | 已展開詳情時移除多餘提示，保留階段耗時。 |
| Help：`--target` 無說明 | 補上 IP／主機名稱／ONVIF URL 與僅限本次連線的說明，複驗通過。 |

同一位 Critic 使用第二份固定執行檔確認全部修正，於該次針對性複驗未發現剩餘
阻塞。這是 **Agent 模擬首次使用，不是真人使用者研究**。未驗證實機、區域網路
搜尋、實機憑證、影片解碼、實際終端縮放或非 Windows 終端。實機互通性及三平台
原生發布／安裝關卡仍待完成。Mock 已停止，合成產物留在已忽略的
`target/cli-manage-review-20260909/`。未變更 Release／tag、遠端分支、已安裝 CLI、
攝影機設定或使用者已保存憑證。
